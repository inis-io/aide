# pay/docs — 设计与需求文档

## 共同约定

- 文档中引用的 SDK 接口均以 `go.mod` 锁定的 `github.com/go-pay/gopay v1.5.122` 为准，已逐一在模块源码中核实签名；升级 gopay 前需复核文档中的接口清单。
- 01–03 互不依赖，但 02 与 03 都会改动 `paypal.go`，03 会改动三个 Provider 的 `checkResponse` / 通知构建路径，实施时建议按 01 → 02 → 03 顺序，避免交叉冲突。04 的主体在业务侧（报价服务），进库改动仅 `CurrencySupporter` 接口，其结算对差环节依赖 01 的 Biller 先落地。
- 所有实施必须遵守 `pay/README.md` 的安全约定：敏感值只走 `SensitiveString` / `SecretRef`，原始报文按 `RawCapture` 策略捕获，日志与观测只出现业务号摘要。
